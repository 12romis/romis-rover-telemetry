# 0003 — Зберігати сирий JSON поруч із колонками, міграції писати SQL-файлами, агрегації — SQL-представленнями

- **Status:** Accepted
- **Date:** 2026-10-23
- **Deciders:** 12romis (власник), Claude (survey)

## Context

Звіти надходять рідко (кілька на день), обсяг даних малий. Контракт може еволюціонувати адитивно; невідомі поля мають зберігатися. Права на запис і читання розділяються за конституцією №10. Стек Postgres 16 уже працює на VPS у контейнері `postgres`.

## Decision drivers

- Еволюція схеми: невідомі поля ігноруються, повний сирий JSON зберігається (конституція №8).
- Найменші права: `ingest` лише вставляє, дашборд лише читає (конституція №10).
- Застосовані міграції не змінюються, зміна схеми — нова міграція (конституція №16).
- Малий обсяг даних: TimescaleDB і ORM не потрібні (`initial-plan.md` §Агрегації).

## Considered options

1. **Сирий SQL + `yoyo-migrations`** (пари up/down), `psycopg` 3 без ORM; колонки + `payload jsonb`; агрегації як SQL-представлення.
2. **SQLAlchemy + Alembic** — ORM і автогенерація міграцій.
3. **Лише `payload jsonb`**, без розібраних колонок, розбір у запитах.

## Decision outcome

**Chosen:** варіант 1. Таблиця `sessions` має природний ключ `(mac, seq)`, розібрані колонки (`NULL` лишається `NULL`) і `payload jsonb`; таблиця `rejected` зберігає невалідні повідомлення. Три ролі Postgres: `owner` (міграції), `ingest` (INSERT), `viewer` (SELECT). Дашборд читає лише SQL-представлення. Міграції — `NNNN_<назва>.sql` і `NNNN_<назва>.rollback.sql`.

## Consequences

**Positive**
- Схема читається прямо з SQL, жодного ORM-шару для вивчення.
- Нове поле контракту не ламає запис: воно лишається в `payload` до окремої міграції.
- Права розділено на рівні БД.

**Negative**
- `yoyo-migrations` з драйвером `psycopg` 3 потребує перевірки в scaffold-задачі S3; у разі несумісності потрібен новий ADR.
- Представлення з агрегаціями доведеться оновлювати міграціями; для малих даних це прийнятно.

**Neutral**
- Якщо обсяг виросте, представлення можна замінити на матеріалізовані без зміни коду дашборду.
