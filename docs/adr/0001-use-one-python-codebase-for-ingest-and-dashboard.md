# 0001 — Використати одну кодову базу на Python 3.12 для ingest і дашборду

- **Status:** Accepted
- **Date:** 2026-10-23
- **Deciders:** 12romis (власник), Claude (survey)

## Context

Потрібні два процеси: підписник MQTT, що пише звіти в Postgres, і публічний дашборд лише для читання. Дедлайн презентації — 2026-10-26, власник один. Стек ingest і дашборду вже вибрано в `docs/inputs/initial-plan.md` (Python, `paho-mqtt` 2.x, `psycopg` 3, FastAPI, ECharts); тут фіксується форма: скільки репозиторіїв, образів і чи потрібна збірка фронтенду.

## Decision drivers

- Дедлайн 2026-10-26 і один розробник: мінімум рухомих частин (`docs/idea-brief.md` §6.1).
- Розбір звіту й похідні метрики потрібні і ingest, і дашборду; дублювати їх не можна (конституція №3, №4).
- Сервіси працюють у Docker-мережі `infra` і виходять назовні лише через Caddy (конституція №12).
- Презентація не має залежати від зовнішньої мережі (графіки мають відкриватися без CDN).
- Інструмент ingest — окремий Python-сервіс, не n8n (`initial-plan.md` §Прийняті рішення).

## Considered options

1. **Один репозиторій, один пакет, один образ, два сервіси** — `ingest` і `web` запускаються різними командами.
2. **Два репозиторії (ingest, dashboard)** — повна ізоляція, спільний код через пакет або копіювання.
3. **Дашборд як SPA (npm, збірка)** — окремий фронтенд-проєкт поверх JSON API.

## Decision outcome

**Chosen:** варіант 1. Один пакет `rover_telemetry`, один `Dockerfile`, у `docker-compose.yml` два сервіси з різними командами запуску. Дашборд — серверні шаблони Jinja2 і Apache ECharts зі `static/` без збірки; CSS один власний файл. Це найменша кількість частин за дедлайн, а спільний `domain` не дублюється.

## Consequences

**Positive**
- Розбір звіту й метрики існують в одному місці та покриті одними тестами на фікстурах.
- Один образ, один CI, одна версія залежностей.
- Дашборд відкривається без CDN і без `npm`.

**Negative**
- Зміна залежності `web` перезбирає образ `ingest` (образ ingest трохи більший за потрібне).
- Без збірки фронтенду нема TypeScript і компонентного підходу; інтерактивність обмежена ECharts і простим JS.

**Neutral**
- Розділити на два репозиторії пізніше можна: межа проходить по модулях `ingest` і `web`, які не імпортують один одного.
