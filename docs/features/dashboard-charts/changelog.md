# Changelog — dashboard-charts

## dashboard-charts — три блоки з графіками на публічному дашборді

**What:** під підсумками на `https://rover.romis.cloud/` з'явилися три блоки, де виїзди стоять на осі за номером сесії (не за часом): «Акумулятор» (напруга на початку, мінімум і наприкінці проти відсічки 6,0 В і повного заряду 8,4 В; просадка), «Перешкоди» (схема ровера з чотирма датчиками й числом спрацювань, найменша відстань на вході в утримання проти порога 190 мм, час вимкненого захисту) і «Рух і борти» (середня й пікова швидкості лівого та правого борту, різниця бортів). Над кожним блоком є опис простою мовою. Відсутнє значення — «немає даних», виміряний нуль — нуль; втрачений номер сесії лишається порожнім слотом із підписом, лінія через нього не йде. Збій одного блоку показує повідомлення замість нього, решта сторінки працює. Графіки малюються локальним `echarts` без звернень до сторонніх вузлів; без скриптів лишаються описи й таблиця.

**Why:** підсумки й таблиця не показували, як ровер працював від виїзду до виїзду, а саме це — мета дашборду; потрібно до презентації 2026-10-26 — див. [spec](spec.md) §1/§2. Ключові рішення — у [adr/](adr/); правило «одне місце для правил відображення» — ADR-0003.

**How to use:** відкрити `https://rover.romis.cloud/` і оновити сторінку після нового виїзду (кешу даних немає).

**Operational notes:**
- Migration: <!-- none -->; читається наявна таблиця `sessions` ролі `viewer`.
- Feature flag / config: <!-- none -->; нові змінні не потрібні.
- Деплой: **потрібна перезбірка образу `web`** (`docker compose build web && docker compose up -d web`) — на момент ship образ у проді старіший за гілку (`charts.js` не збігається). `ingest` не зачіпається.
- Rollback: повернути попередній образ `web` (`git checkout main` + перезбірка); `ingest` і дані не залежать від дашборду.

**Acceptance criteria delivered:** AC-01…AC-23 (блоки «Акумулятор», «Перешкоди», «Рух і борти», «немає даних» проти нуля, втрачені сесії на осі, описи простою мовою, ізоляція збою блоку, актуальність, HTTPS без сторонніх вузлів). Відкладені зауваження рев'ю (H1–H8, 360 px, підписи слотів) — spec §8, owner 12romis.
