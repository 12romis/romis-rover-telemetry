# 0004 — Рахувати втрачені сесії SQL-представленням від найменшого збереженого номера

- **Status:** Accepted
- **Date:** 2026-10-23
- **Deciders:** 12romis (власник), Claude (design)

## Context

Пропуск у `seq` для одного `mac` означає втрачену сесію (контракт, конституція №6). Облік веде від найменшого збереженого номера ровера (рішення власника №7, AC-08), а порядок отримання довільний, тож сесія, що була втраченою, може з'явитися пізніше (AC-09), а менший номер може зсунути початок обліку. Облік читає дашборд (кроки 3–6 роудмапу) і Власник ровера через SQL (SAD §5, data-model).

## Decision drivers

- AC-08, AC-09, AC-17: облік має сходитися при довільному порядку доставки без додаткових дій сервісу.
- Роль `ingest` лише дописує (конституція №10): стан обліку не повинен вимагати її оновлень.
- Видимі втрати в межах 1 хв після появи пропуску (spec §7, пропозиція).
- Обсяг малий: ровер їздить щодня, виїздів небагато (`docs/idea-brief.md` §4).

## Considered options

1. **SQL-представлення `session_gaps`** з `generate_series` від `min(seq)` до `max(seq)` для кожного `mac` мінус збережені номери; нічого не зберігається.
2. **Таблиця пропусків**, яку оновлює тригер або `ingest` під час запису.
3. **Облік у коді дашборду**, а не в БД.

## Decision outcome

**Chosen:** варіант 1. Облік завжди відповідає збереженим даним: запізніла сесія сама зникає з пропусків, менший номер сам зсуває початок. Роль `viewer` читає представлення, роль `ingest` про нього не знає. Варіант 2 потребує оновлень і тригерів для ролі, що лише дописує; варіант 3 розмазує правило між шарами і не дає Власнику ровера готового обліку в сховищі (AC-08).

## Consequences

**Positive**
- Жодного стану обліку, що міг би розійтися з даними.
- Правило в одному місці й перевіряється SQL-тестом на синтетичному наборі.

**Negative**
- Розмір ряду `generate_series` росте з діапазоном номерів; для малого обсягу не проблема.
- Підробний звіт із далеким майбутнім номером створить хибний довгий «пропуск» (SAD §11, захист — права ACL).

**Neutral**
- За потреби представлення замінюється матеріалізованим без зміни споживачів.
