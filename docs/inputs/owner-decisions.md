# Рішення власника (2026-10-23)

Відповіді на відкриті питання після початкового плану. Джерело для spec §8 і ADR.

| # | Питання | Рішення |
|---|---|---|
| 1 | Мова | Коміти — англійською; документи й коментарі — українською; README — двомовний |
| 2 | Коміти під час SDD | Локальні коміти дозволені (`auto_commit: per_task`); push — лише за вказівкою |
| 3 | GitHub | `git@github.com:12romis/romis-rover-telemetry.git`; встановити `gh` |
| 4 | Доступ до дашборду | Наразі публічний, без автентифікації |
| 5 | ACL брокера | Звузити разом із появою ingest: `RomisRover` — лише запис у `rover/+/session`; `rover-ingest` — читання; `rover-viewer` — читання для MQTT Explorer. Один спільний логін для роверів, поки ровер один |
| 6 | Резервні копії | Щоденний `pg_dump` бази `rover` на цьому ж сервері, зберігання 30 днів |
| 7 | Пропуски `seq` | Рахувати лише від першого отриманого `seq` для кожного `mac` (сесії 1–25 до появи доступу до брокера не враховувати) |
| 8 | Заряд | Лише вольти: на акумулятор і на банку (÷2, акумулятор 2S); відсотків немає |
| 9 | Цикли заряду | Напруга повного заряду 2S — 8.4 В (8400 мВ). Точне правило визначення нового циклу уточнити в spec |
| 10 | Назва ровера | `288485922c94` → «RomisRover»; поки ровер один |
| 11 | Часовий пояс | `received_at` показувати в Europe/Kyiv |
| 12 | Сповіщення (Telegram через n8n) | Не в першій версії |
| 13 | Пристрої | Ноутбук і телефон; телефон теж має бути зручним |
| 14 | `holds.by_sensor` | Очікувана поведінка: рахує всі датчики обох секторів, що на вході в утримання були нижче порога (seq 27: `front`, `right_front`, `rear` в одному утриманні) |
